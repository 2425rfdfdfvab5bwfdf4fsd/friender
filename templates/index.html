💬 Slack
Connect Slack
1. Go to api.slack.com/apps → create a new app
2. Add scopes: channels:read, chat:write, channels:history, search:read
3. Install app to workspace → copy Bot User OAuth Token
4. Add SLACK_BOT_TOKEN to Secrets
📋 Trello
Connect Trello
1. Go to trello.com/app-key → copy your API key
2. Click "Generate a Token" on the same page
3. Add TRELLO_API_KEY and TRELLO_API_TOKEN to Secrets
🎵 Spotify
Connect Spotify
1. Go to developer.spotify.com/dashboard → create an app
2. Copy Client ID and Client Secret
3. Add SPOTIFY_CLIENT_ID and SPOTIFY_CLIENT_SECRET to Secrets
For playback control also add SPOTIFY_ACCESS_TOKEN
